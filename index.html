Flyer Link Splitter

Drop the monthly Flipp Flyer Template workbook. You get three values-only files, one per store: Harvest Wines, Rockhead and Westside.

What the tool does

  • Finds the Links sheet (for example Links-October) by its Page / SKU / store ID and Link headers. Links-Template is skipped.
  • Keeps every row that has a product, SKU, ID or a custom link. Empty slots and empty pages at the bottom are dropped.
  • Fills the page number down onto every row.
  • Writes values only, with no formulas. Links stay clickable.
  • Names each file after the one you drop, plus “ - Harvest Wines”, “ - Rockhead” or “ - Westside”.
  • Everything runs in your browser. The workbook is never uploaded.
